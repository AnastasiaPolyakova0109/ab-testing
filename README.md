# A/B-тестирование и проверка статистических гипотез

Учебный проект по статистическому анализу на Python. В первой части сравниваем конверсию в A/B-тесте. Во второй анализируем, какие факторы связаны с подпиской на банковский депозит.

| Часть | Что внутри |
| --- | --- |
| [1. A/B-тест посадочной страницы](01-ab-test.ipynb) | Очистка данных, проверка баланса групп и сравнение конверсии контрольной и экспериментальной версий. |
| [2. Гипотезы по банковской кампании](02-hypothesis-testing.ipynb) | Разведочный анализ и проверка семи гипотез о подписке на депозит, в том числе с помощью критерия χ² и логистической регрессии. |

## Как запустить

Откройте ноутбуки в Jupyter. Установите `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, `statsmodels` и `plotly`. Положите CSV рядом с ноутбуками.

- Для части 1 нужен исходный файл `data_ab.csv`. В репозитории его нет, но в ноутбуке сохранены графики и результаты.
- Для части 2 скачайте `bank-full.csv` из архива `bank.zip`. [Bank Marketing, UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/222/bank+marketing)
